# Harbour 0.4.2 — Mole for Mac 功能還原計劃

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** 以已通過 CI 嘅 0.4.1（`61c74fb`）為基礎，將 Mole for Mac 五大頁面中 GUI 仍缺失嘅核心功能，喺 HarbourMac 逐一還原，每項都經 macOS CI 驗證。

**Architecture:** SwiftUI GUI 透過 Runner 呼叫內置引擎（`bridge.sh`／`status-go`／`analyze-go`）；GUI 只做呈現同確認，引擎做實際工作。新功能優先用現成 engine 資料，唔另寫有風險嘅系統操作。

**Tech Stack:** Swift 5.7（macOS 12+）、SwiftUI、AppKit、Swift Package Manager、GitHub Actions `macos-15-intel`。

## 里程碑 M1：操作紀錄頁功能補完（對應 Mole「操作紀錄」）

Mole App 有完整操作歷史（做過乜、幾時、影響幾多 bytes、可還原狀態）。Harbour 已有 `HistoryView`（`DataViews.swift:147`）但只顯示 sessions＋deletions 兩個清單，冇統計摘要、冇重新清理入口。

### Task 1.1 — History 摘要列
**Objective:** 頂部顯示「本月共 N 次操作、清理 X bytes」摘要。

**Files:**
- Modify: `Sources/HarbourMac/DataViews.swift`（HistoryView 內）
- Test: `Tests/HarbourMacTests/HistorySummaryTests.swift`（新）

**Step 1: 寫失敗測試** — `HistorySummary.make(from: [String: Any]) -> (count: Int, bytes: Int64)`，fixture 用真實 `mole history --json` schema：
```swift
func test_summary_counts_sessions_and_bytes() {
    let json: [String: Any] = ["sessions": [["command": "clean", "status": "success"], ["command": "optimize", "status": "ok"]],
                                "deletions": [["size": 1024], ["size": 2048]]]
    let summary = HistorySummary.make(from: json)
    XCTAssertEqual(summary.count, 2)
    XCTAssertEqual(summary.bytes, 3072)
}
```
**Step 2:** `swift test`（CI）預期失敗：`HistorySummary` 未定義。
**Step 3:** 喺 `HarbourApp.swift` 或 DataViews.swift 加 `struct HistorySummary { static func make(...) }`。
**Step 4:** 測試通過。
**Step 5:** Commit `feat: history summary strip`。

### Task 1.2 — 清理後快速重掃
**Objective:** History 頁每個 session 加「再清理一次」按鈕，只喺 command 係 `clean`／`optimize` 時出現，點擊等於回到對應頁並預覽，**唔會直接執行**。
**Files:** `DataViews.swift`（HistoryView records 迴圈）、`HarbourApp.swift`（AppModel 加 `replay(session:)`）。
**驗證：** NavigationTests 加一條：replay 只改 `page`，唔會呼叫 runner。
**Commit:** `feat: history replay button`
